# Task Management System - Frontend

Aplikasi antarmuka pengelolaan tugas berbasis web yang dirancang dengan React, Vite, dan Tailwind CSS. Proyek ini mengonsumsi REST API dari backend Golang.

## Teknologi
* **Framework:** React + Vite
* **Routing:** React Router v6
* **HTTP Client:** Axios (dengan Interceptor untuk JWT)
* **Styling:** Tailwind CSS
* **Ikon & UI:** Lucide React & React Hot Toast

## Prasyarat
* Node.js (v18 atau lebih baru)
* Backend Golang API yang sudah berjalan di `http://localhost:8080`
